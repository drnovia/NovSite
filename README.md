## 💖 Tentang

NovSite adalah situs promosi single-page: Navbar, Hero, Work grid, About, Services, CTA, Footer. Tailwind v3 + GSAP untuk intro dan scroll reveals.

## 🛠 Instalasi

```bash
git clone https://github.com/drnovia/NovSite.git
cd NovSite
npm install
```

## 🚀 Pemakaian

| Perintah | Fungsi |
| --- | --- |
| `npm run dev` | Dev server |
| `npm run build` | Output ke `dist/` |
| `npm run preview` | Preview statis |
